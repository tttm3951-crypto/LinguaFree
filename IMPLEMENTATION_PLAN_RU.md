# LinguaFree — пошаговый план улучшения и проверка

## Этап 1. Содержание (реализовано в коде)
1. Сохранить все 300 уроков и семь вопросов на урок.
2. Сохранить оригинальные вопросы, не обнуляя прогресс по номерам уроков.
3. Заменить повторяющиеся наборы уроков новыми комбинациями, используя оригинальные диалоги из stories.json и исходный словарь.
4. Сохранить существующую базу из 746 уникальных вопросно-ответных пар и дополнить её естественными фразами.
5. Контролировать автоматическими тестами отсутствие идентичных полных уроков и не менее 900 уникальных пар вопрос–ответ.
6. Редакторская проверка уровня, грамматики и естественности каждого предложения — отдельный этап, не подменяемый структурным тестом.

## Этап 2. Звук и речь (реализовано частично)
1. Использовать собственные синтезированные сигналы успеха, ошибки и достижения (без чужих аудиофайлов).
2. Оставить настройки скорости речи, медленное повторение и выбор лучшего установленного офлайн-голоса Android.
3. Сравнивать распознанную английскую фразу с эталоном по последовательности слов и показывать процент совпадения.
4. Честно обозначать: распознавание слов не равно фонетическому анализу акцента.
5. Для настоящей оценки произношения потребуется отдельный фонетический движок и тесты на реальных устройствах.

## Этап 3. Лисичка (реализовано в коде)
1. Нарисовать оригинального персонажа в Canvas с прозрачным фоном.
2. Анимировать уши, моргание, рот и лапы независимо.
3. Ввести состояния curious, happy, surprised, support, celebrate.
4. Привязать реакции к правильным/неправильным ответам, речевой практике и историям.
5. Проверить анимации и производительность на телефоне.

## Этап 4. Контроль
1. Проверить JSON автоматическим скриптом scripts/validate_content.py.
2. Собрать APK в GitHub Actions.
3. Протестировать установку, переходы между экранами, озвучку, микрофон, подсказки и лисичку на Android.
4. Исправить обнаруженные ошибки; не считать тестирование на реальном устройстве завершённым до фактической проверки.
