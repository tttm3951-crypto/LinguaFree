# Формат контента LinguaFree (схема v1)

Весь курс — JSON-файлы в `core/data/src/main/assets/content/`. Приложение читает их при
первом запуске и при каждом изменении `contentVersion`, проверяет и кладёт в Room.
Прогресс хранится отдельно по стабильным `id`, поэтому новые уроки и правки текстов
его не сбрасывают. **Чтобы добавить юнит или урок, код менять не нужно.**

```
content/
├── course.json      # разделы и порядок юнитов
├── units/u01.json   # юнит: баннер, справочник, узлы пути с упражнениями
├── lexemes.json     # слова и фразы для интервального повторения
└── lexicon.json     # подсказки по тапу на слово (en→ru и ru→en)
```

Генератор `scripts/content/build_course.py` собирает эти файлы из авторских данных
(`scripts/content/a1_start.py`) и библиотеки LinguaFree 0.9 (`assets/library/`).
JSON можно править и вручную. Перед коммитом запускайте `python3 scripts/content/validate_content.py`;
те же правила при загрузке проверяет `ContentValidator` в приложении.

## Версии

| Поле | Где | Смысл |
|---|---|---|
| `schemaVersion` | во всех файлах | версия формата. Приложение 1.0 понимает `1`; файлы новее отклоняются с понятной ошибкой |
| `contentVersion` | `course.json` | увеличивайте при любом изменении контента — приложение перечитает файлы |

## course.json

```json
{
  "schemaVersion": 1,
  "contentVersion": 1,
  "id": "en-ru",
  "title": "Английский для русскоязычных",
  "sections": [
    { "id": "s1", "title": "Раздел 1 · Старт", "cefr": "A1",
      "description": "Первые слова и фразы", "units": ["u01", "u02", "u03"] }
  ]
}
```

## units/<id>.json

```json
{
  "schemaVersion": 1,
  "id": "u01",
  "title": "Приветствия и знакомство",
  "description": "Здороваемся и рассказываем о себе",
  "color": "#4CC417",
  "guidebook": [
    { "title": "Я — I am", "text": "Краткое правило на русском…",
      "examples": [ { "en": "I am Anna.", "ru": "Я Анна." } ] }
  ],
  "nodes": [ … ]
}
```

`guidebook` — «Справочник» юнита (кнопка на баннере). `color` — цвет баннера `#RRGGBB`.

### Узлы пути (`nodes`)

| `type` | Что это | `exercises` |
|---|---|---|
| `lesson` | урок, 12–15 упражнений; `newWords` — id новых лексем, **не больше 5** | обязательны |
| `story` | история/диалог; минимум одно упражнение `dialogue` | обязательны |
| `chest` | сундук с кристаллами | пусто |
| `review` | повторение юнита — собирается из слабых слов автоматически | пусто |
| `test` | проверка юнита; через неё же юнит можно пропустить. Ровно один на юнит | пусто |

```json
{ "id": "u01-l1", "type": "lesson", "title": "Привет!",
  "newWords": ["hello", "hi"], "exercises": [ … ] }
```

Узлы открываются строго по порядку. `id` узлов и упражнений уникальны во всём курсе
и не должны меняться, иначе потеряется прогресс.

### Упражнения

Общие поля:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | уникальный id |
| `type` | string | один из 9 типов ниже |
| `order` | int | порядок в уроке |
| `text` | string | основной текст: предложение для перевода, слово, фраза для чтения, предложение с `___` |
| `instruction` | string? | своя инструкция вместо стандартной для типа |
| `subtitle` | string? | пояснение под текстом (например, перевод для `fill_gap`) |
| `direction` | `ru_en` \| `en_ru` | направление перевода |
| `options` | string[] или `{text, image}`[] | варианты, плитки, карточки |
| `answers` | string[] | все принимаемые ответы; первый показывается как правильный |
| `audio` | string? | текст для озвучки (TTS) или `asset:audio/file.ogg` для записи |
| `image` | string? | картинка к заданию (имя VectorDrawable) |
| `lexemes` | string[] | id лексем из `lexemes.json` — для интервального повторения |
| `hints` | {слово: перевод}? | подсказки по тапу, дополняют `lexicon.json` |

Типы (`type`):

| Тип | Упражнение | Обязательно |
|---|---|---|
| `tiles` | перевод предложения плитками (тап или перетаскивание) | `text`, `direction`, `options` (плитки, в т. ч. лишние), `answers` |
| `type` | перевод с вводом текста | `text`, `direction`, `answers` |
| `select_image` | выбор картинки к слову | `text`, 4 `options` с `image`, `answers` |
| `match` | сопоставление пар | `pairs`: ровно 5 `{en, ru}` |
| `listen_tiles` | прослушать и собрать | `audio`, `options`, `answers` |
| `listen_type` | прослушать и напечатать | `audio`, `answers` |
| `fill_gap` | заполнить пропуск | `text` с `___`, `options`, `answers` |
| `speak` | прочитать вслух | `text`, `audio`, `answers` |
| `select_translation` | выбор перевода | `text`, `options`, `answers` |
| `dialogue` | мини-диалог с вопросами | `lines`: `{speaker, en, ru}`, `questions`: `{prompt, options, answer}` (индекс) |

Проверка ответов не зависит от регистра, пунктуации и `ё/е`; английские сокращения
раскрываются (`don't` = `do not`, `I'm` = `I am`). В `type` и `listen_type`
допускаются опечатки: до 1 в словах из 4–7 букв и до 2 в более длинных. Короткие слова
(`he/she`, `a/the`) должны совпадать точно.

Пример:

```json
{ "id": "u02-l1-t0", "order": 2, "type": "tiles", "direction": "ru_en",
  "text": "Воду, пожалуйста.",
  "options": ["thank", "tea", "juice", "Water", "please", "coffee"],
  "answers": ["Water, please."],
  "lexemes": ["water"] }
```

## lexemes.json

```json
{ "schemaVersion": 1,
  "lexemes": [ { "id": "water", "word": "water", "translation": "вода", "image": "img_water" } ] }
```

Для каждой лексемы приложение хранит силу знания (0–1), дату последнего показа,
число верных ответов и ошибок и период полураспада памяти (модель half-life regression).

## lexicon.json

`{ "schemaVersion": 1, "hints": { "water": "вода", "вода": "water" } }` — подсказки
по тапу на слово в задании. Ключи — в нижнем регистре.

## Картинки

Картинки — векторные `img_*.xml` в `core/ui/src/main/res/drawable/`. Нарисованы для LinguaFree
(`scripts/icons/illustrations.py`). Чтобы добавить картинку, опишите SVG в этом файле и
сконвертируйте, как сказано в `scripts/icons/README.md`.

## Правила методики (проверяет валидатор)

- в уроке ≥ 12 упражнений (цель 12–15) и ≤ 5 новых слов;
- в курсе задействованы все 9 типов упражнений;
- ответ выбора есть среди вариантов; из плиток можно собрать первый ответ;
- у `select_image` ровно 4 карточки с существующими картинками; у `match` — 5 уникальных пар.
