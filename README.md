# LinguaFree

Английский для начинающих на Android, без рекламы. Android 7.0+.

[Скачать подписанный APK](https://github.com/tttm3951-crypto/LinguaFree/releases/latest) · [Что нового](RELEASE_NOTES_RU.md) · [Сообщить об ошибке](https://github.com/tttm3951-crypto/LinguaFree/issues)

24 темы с нуля / 120 заданий, 300 основных уроков, 20 тем грамматики A1–B2, 70 историй, шесть анимированных лис и исходный аватар. Расширенный офлайн-справочник содержит 150 000 уникальных пар EN/RU (635 учебных записей + 149 365 пар предложений Tatoeba), а не 150 000 отдельных слов.

Прогресс и настройки хранятся локально. Новые подписанные версии устанавливаются поверх приложения с сохранением данных. Постоянный сертификат проверяется сборкой; тест обновления проверяет XP, уроки, имя, аватар и настройки. Сначала экспортируйте прогресс, если переходите с экспериментального APK с другим ключом.

Сборка: Java 17, Gradle 8.9, Android SDK 35. Перед Gradle выполните `python3 scripts/build_offline_library.py`, затем скопируйте `fox_original.png` в `app/src/main/res/drawable/`. Корпус загружается только машиной сборки и проверяется по SHA-256; на телефоне он встроен в APK. См. [источник и лицензии](OFFLINE_DATA_RU.md).

Для локального запуска: `gradle testDebugUnitTest assembleDebug`. Постоянная подпись и проверка обновления: Actions → Signed release and upgrade check. Для нового выпуска увеличьте versionName и versionCode в app/build.gradle.kts, обновите RELEASE_NOTES_RU.md; ключ не меняйте. Публикация не заменяет уже выпущенный APK с тем же тегом.

Cloudflare не опубликован: онлайн-синхронизация пока недоступна. Ручные отчёты и резервные копии работают без сервера. Офлайн-озвучка требует установленного английского голоса Android. Оценки акцента и полного облачного восстановления нет.
