# LinguaFree 🦊

Бесплатное Android-приложение для изучения английского языка для русскоязычных.
Короткие уроки, путь из юнитов, опыт (XP), серии дней, сердца, лиги и мгновенная
обратная связь — а рядом весёлый лисёнок, который радуется вместе с тобой.

[Скачать APK](https://github.com/tttm3951-crypto/LinguaFree/releases/latest) ·
[Что нового](RELEASE_NOTES_RU.md) · [Сообщить об ошибке](https://github.com/tttm3951-crypto/LinguaFree/issues)

## Принципы

- **Бесплатно** — весь контент и все функции доступны полностью.
- **Без рекламы** — ни баннеров, ни «посмотри видео за награду».
- **Без подписок и покупок** — кристаллы зарабатываются только обучением.
- **Без трекеров** — никакой аналитики и сторонних SDK.
- **Офлайн** — у приложения нет разрешения на интернет; прогресс хранится только на телефоне.

Эти правила проверяются автоматически в CI: сборка падает, если появится рекламная,
платёжная или аналитическая библиотека либо лишнее разрешение.

## Что внутри

- Путь обучения: разделы → юниты с цветным баннером и справочником → уроки, сундуки,
  истории, повторение и проверка юнита. Юнит можно пропустить, сдав проверку.
- Урок из 10–15 упражнений девяти типов: плитки, ввод текста (с допуском опечаток),
  картинки, пары, аудирование, пропуск, говорение, выбор перевода, мини-диалог.
- Сердца с честными правилами: бесплатная практика восстанавливает все сердца;
  есть «Режим без сердец».
- Серия дней с заморозками, ежедневные квесты, месячный значок, достижения.
- Лиги на 30 участников (10 уровней).
- Магазин за кристаллы: заморозки серии, наряды лисёнка и темы оформления.
  Сердца за кристаллы не продаются — только бесплатная практика или ожидание.
- Интервальное повторение слов (half-life regression), практика слабых слов и ошибок.
- Наследие LinguaFree 0.9 сохранено: 300 уроков, 70 историй, 20 тем грамматики,
  курс «с нуля», словарь из 635 выражений и офлайн-справочник на 150 000 пар.

## Стек

Kotlin, Jetpack Compose (Material 3), minSdk 26 / targetSdk 35, Gradle Kotlin DSL +
version catalog. Clean Architecture + MVVM, Hilt, Navigation Compose, Coroutines/Flow,
Room, DataStore, WorkManager, Android TextToSpeech, SpeechRecognizer, Media3, Lottie.
Тесты: JUnit5, Turbine, Compose UI Test. Шрифт Nunito (SIL OFL 1.1).

## Сборка

Нужны JDK 17 и Android SDK 35.

```bash
python3 scripts/build_offline_library.py   # собрать офлайн-справочник (один раз)
./gradlew assembleDebug                    # APK: app/build/outputs/apk/debug/
./gradlew lint test                        # проверки и тесты
```

Release-сборка (`./gradlew assembleRelease`) использует R8; ключ подписи передаётся
только через переменные окружения CI и в репозиторий не попадает.

## Структура модулей

| Модуль | Назначение |
|---|---|
| `:app` | точка входа, навигация, нижняя панель, уведомления |
| `:core:domain` | бизнес-логика без Android: ответы, SRS, серия, сердца, XP, лиги, квесты |
| `:core:data` | Room, DataStore, загрузка и проверка контента, озвучка и распознавание речи |
| `:core:ui` | тема `LinguaFreeTheme`, компоненты, лисёнок, иконки |
| `:feature:*` | экраны: onboarding, path, lesson, practice, profile, leagues, shop |

## Как добавлять контент

Курс описан JSON-файлами в `core/data/src/main/assets/content/`. Формат с версией схемы
описан в [docs/content-format.md](docs/content-format.md): чтобы добавить юнит или урок,
код менять не нужно. Перед коммитом запустите `python3 scripts/content/validate_content.py`.
