# Кабинет преподавателя LinguaFree 0.5

## Как пользоваться на двух телефонах
1. На телефоне ученика открыть «Мои достижения» → «Сохранить отчёт для отправки».
2. Ученик выбирает место сохранения JSON-файла и добровольно отправляет его преподавателю через мессенджер, Bluetooth или другое средство.
3. На телефоне преподавателя установить LinguaFree, открыть «Мои достижения» → «Кабинет преподавателя» → «Загрузить отчёт ученика».
4. Выбрать присланный файл. Появится карточка ученика с количеством уроков, XP, днями активности, датой последнего занятия, ошибками и результатами по навыкам.
5. При получении следующего отчёта загрузить его снова: появится разница между двумя последними отчётами.
6. Кнопка «Удалить отчёты ученика» удаляет все импортированные отчёты выбранного имени с телефона преподавателя.

## Ограничения
- Нет удалённого доступа, фонового слежения, автоматического сбора геолокации и скрытого мониторинга.
- Отчёты отражают использование приложения, но не доказывают физическое присутствие или самостоятельность выполнения.
- Приложение работает без интернета; интернет может понадобиться только для отправки файла.
- Имя ученика служит идентификатором в текущем прототипе. Два ученика с одинаковым именем могут объединиться в одну карточку. Перед использованием в большой группе потребуется устойчивый локальный идентификатор ученика и процедура согласованной привязки.
- Даты, XP и другие значения берутся из локального отчёта, не являются криптографически подтверждёнными. Внешняя правка JSON не обнаруживается.
- При изменении имени ученика старые и новые отчёты могут показываться в разных карточках.
- На телефоне преподавателя хранится не более 250 последних загруженных отчётов.
- Данные кабинета хранятся в `linguafree_teacher`, отдельно от `linguafree_progress`, и удаляются при очистке данных приложения. Автоматического резервного копирования кабинета пока нет.
- Отчёты учеников могут содержать персональные данные. Получайте их добровольно, не публикуйте, удаляйте по запросу и не пересылайте третьим лицам.

## Что проверить перед использованием
- Импорт корректного файла отчёта и отклонение неверного JSON.
- Отображение второго отчёта и изменения прогресса.
- Удаление данных ученика.
- Отсутствие смешения собственного прогресса с импортированными отчётами.
- Установка APK на реальное устройство и сохранение данных после перезапуска.
- При обновлении установленной версии необходимо проверить подпись APK: без совпадения подписи обновление не установится поверх старого.
