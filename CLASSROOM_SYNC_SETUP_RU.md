# Синхронизация LinguaFree: состояние протокола 2

Публикация сервера приостановлена владельцем. Пустой KV namespace создан, но Worker, HTTPS /health и обмен двух телефонов не подтверждены. Cloudflare API-токен не выпускался. Не включайте работу с данными детей на основании зелёных unit-тестов.

Клиент поддерживает добровольное подключение, постоянную очередь последнего снимка, отправку после сохранения, WorkManager с сетевым ограничением, ревизии и snapshot ID, повтор удаления при отзыве. Преподаватель видит подключения до первого отчёта, обновляет код, удаляет доступ, читает кэш и может включить периодические фоновые уведомления (не мгновенный push).

Сервер требует CLASSROOMS Durable Object (SQLite migration), CLASSROOM_KV и native RATE_LIMITER, как в backend/cloudflare-worker/wrangler.toml. KV используется как индекс кодов; записи класса сериализованы в Durable Object. Создание кабинетов закрыто ALLOW_CLASSROOM_CREATION=false. Флаг нельзя открывать до настройки регистрации/допуска преподавателей и процесса согласия.

Действует ограничение 60 запросов/60 секунд на ключ в локации Cloudflare, до 200 записей подключений в классе, очистка после 90 дней неактивности. Ревокация блокирует последующие отправки; временные служебные записи удаления не равны учебному отчёту. Это не глобальная точная квота.

Для будущего разрешённого развёртывания используйте deploy-classroom.yml и HTTPS endpoint через LINGUAFREE_CLASSROOM_URL. Токен хранится только в GitHub Secrets; значения не публиковать. Перед заменой активного протокола 1 нужна миграция, простая перезапись Worker небезопасна. После развёртывания проверить /health (protocol=2), изоляцию двух классов, offline/retry/revoke/expired invitation на тестовых устройствах.

Сервер хранит сводку, не полную резервную копию. Для восстановления учебного прогресса нужен экспортированный файл. Восстановления учётной записи преподавателя нет; локальный токен нельзя выдавать за восстанавливаемую учётную запись. Юридически достаточное согласие не обеспечивается одной галочкой.
