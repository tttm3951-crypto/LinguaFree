# Настройка защищённого сервера LinguaFree 0.7

**Состояние:** серверный код готов к публикации, но сервер не развёрнут. Адрес приложения заполняется только после развёртывания. Без аккаунта Cloudflare и разрешения владельца невозможно автоматически создать инфраструктуру.

## Публикация через GitHub Actions
1. В Cloudflare создать аккаунт, Worker и KV namespace (название CLASSROOM_KV).
2. Создать Cloudflare API Token с минимально необходимыми правами на Worker Scripts и Workers KV для своего аккаунта. Не публиковать токен.
3. В репозитории GitHub открыть Settings → Secrets and variables → Actions.
4. В **Secrets** добавить `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.
5. В **Variables** добавить `CLASSROOM_KV_ID` (32-символьный идентификатор KV namespace).
6. Открыть Actions → **Deploy Classroom Server** → Run workflow. Рабочий процесс проверит настройки и выполнит `wrangler deploy`.
7. Скопировать опубликованный URL вида `https://linguafree-classroom.<subdomain>.workers.dev` из вывода развёртывания.
8. В **Variables** добавить `LINGUAFREE_CLASSROOM_URL` с этим URL, без завершающего слеша.
9. Запустить Actions → **Build Android APK** → Run workflow. В новой сборке адрес сервера будет задан автоматически.
10. Проверить ответ `/health`, подключение по коду, отправку прогресса и отзыв доступа на двух тестовых телефонах.

**Не отправляйте API-токены и ключи в чат.** Добавляйте их только в GitHub Secrets.

## Работа приложения
Преподаватель открывает «Мои достижения» → «Кабинет преподавателя» и создаёт код подключения. Ученик вводит его в своём приложении и добровольно разрешает передачу. После этого при открытии LinguaFree с доступным интернетом отчёт отправляется на сервер. Преподаватель видит новые записи при открытом кабинете (обновление раз в минуту) и локальное уведомление.

## Безопасность и ограничения публичного запуска
- Все обращения по HTTPS; токены доступа к ученику и кабинету генерируются сервером, хранятся в Android SharedPreferences и проверяются по SHA-256 на сервере.
- **Нет полноценной учётной записи преподавателя с восстановлением доступа.** При очистке данных телефона токен кабинета теряется.
- Создание кабинетов доступно публично; до запуска для большого числа пользователей нужно ограничить создание через Cloudflare WAF/rate limiting или отдельную регистрацию преподавателя. Без этого сервер уязвим к злоупотреблению ресурсами.
- Cloudflare KV не обеспечивает строгую согласованность между регионами. Для критичных данных и гарантированной доставки событий понадобится более надёжное хранилище/очередь.
- Код подключения действует 24 часа, но может использоваться несколькими учениками.
- Ученик может удалить свой отчёт на сервере. При отсутствии сети повторите запрос позже.
- Текущие уведомления формируются только при открытом кабинете. Для уведомлений при закрытом приложении нужен отдельный push-провайдер (например, FCM).
- Отчёты нельзя считать подтверждением физического присутствия на уроке.
- Для использования с несовершеннолетними необходимо оформить надлежащие уведомления и согласия, политику обработки данных и процедуру удаления.
- Перед публичным запуском провести тесты на двух реальных телефонах и настроить постоянную подпись Android APK.
