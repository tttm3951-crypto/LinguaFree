# LinguaFree 0.4 — аудит готовности к реальному запуску

Дата: 17.10.2026. Метод: проверка исходников Kotlin, AndroidManifest.xml, Gradle, GitHub Actions, JSON-ресурсов и истории автоматических сборок. **Не является результатом установки и тестирования на физических устройствах.**

## Реально проверенные показатели контента
- 300 уроков, по 7 вопросов = 2100 вопросов.
- 932 уникальные пары «вопрос — правильный ответ».
- 300 уникальных полных наборов уроков (полностью одинаковых уроков не обнаружено).
- 70 оригинальных коротких историй, 210 двуязычных строк.
- 635 англо-русских словарных записей, 338 с контекстными примерами; 297 пока без отдельного предложения.
- Полный текст уроков, историй и словаря находится в assets, для поиска и прохождения интернет не нужен.
- Проверка структуры контента автоматизирована scripts/validate_content.py, регрессия функций — scripts/validate_app_contract.py.

## Персонализация — реализовано
- Ввод имени/псевдонима при первом запуске, необязателен; ограничение 24 символа.
- Обращение по имени на главной странице, в задании и поздравлении; редактирование в «Мои достижения».
- Имя хранится в `linguafree_progress`, входит в экспорт JSON; идентификатор приложения `org.linguafree.app` сохранён.
- Персонализация не меняет оригинальные английские ответы и проверку заданий.

## Проверенные по коду функции
- Сохранение XP, алмазов, пройденных уроков, ошибок, серии дней, ежедневной цели.
- Истории, словарь, карточки слов, интервальное повторение, игровые задания.
- Напоминания через AlarmManager, восстановление после перезагрузки через BOOT_COMPLETED, разрешение POST_NOTIFICATIONS.
- Анимации оригинальной лисички, звуковые сигналы и вибрация, переключатель эффектов.
- Ручной экспорт/импорт локального прогресса; экспорт проверяет успешное открытие файла.
- Отсутствие INTERNET-разрешения в манифесте. Android TTS/RecognizerIntent являются внешними системными компонентами.

## Найденные дефекты и внесённые исправления
1. Имя не поддерживалось — добавлены ввод, редактирование, отображение в заданиях.
2. Дневная цель в onboarding называлась минутами, но считала занятия — исправлены подписи и варианты.
3. Вступительный звук игнорировал выключенные эффекты — теперь проверяется настройка.
4. Серия занятий могла показываться активной после долгого перерыва — исправлено отображение текущей серии.
5. Карточки разных значений одного английского слова конфликтовали в признаке «выучено» — ключ стал включать перевод.
6. Добавлены регрессионные проверки имени, звука и дневной цели.
7. Настроен **опциональный** выпуск подписанного release APK, но для его активации нужны секреты GitHub.

## Блокеры публичного релиза (GO/NO-GO)
**NO-GO, пока не выполнено следующее:**
1. **Постоянная подпись.** Текущая сборка debug не гарантирует обновление поверх старого APK. Для подписанного релиза владелец должен безопасно создать и хранить один и тот же keystore и добавить четыре GitHub Actions secrets: `LINGUAFREE_KEYSTORE_B64` (base64 всего файла keystore), `LINGUAFREE_STORE_PASSWORD`, `LINGUAFREE_KEY_ALIAS`, `LINGUAFREE_KEY_PASSWORD`. Никогда не загружать приватный keystore в GitHub-репозиторий. Установка поверх прежней версии возможна только при совпадении сертификата подписи.
2. **Тестирование обновления и восстановления данных.** Проверить установку APK поверх прежней сборки, сохранение XP, имени, пройденных уроков, настроек, уведомлений и карточек. Если подпись отличается, не удалять старую версию до резервного копирования.
3. **Ручные испытания на Android 7, 10, 13, 15/16** либо эквивалентных эмуляторах: старт, onboarding, 300 уроков (выборочно), истории, словарь, карточки, аудио, голос, вибрация, разрешения, фоновые напоминания, поворот экрана, длинное имя, плохие резервные копии.
4. **Качество контента.** 932 уникальных пары на 2100 вопросов означают заметные повторы отдельных заданий, хотя полностью одинаковых уроков нет. Необходимо лингвистическое редактирование 297 словарных записей без примеров, проверка перевода и уровней.
5. **Речь офлайн.** Текущий Android RecognizerIntent проверяет совпадение распознанных слов, а не качество акцента. Офлайн-работа зависит от установленных пакетов и реализации Android.
6. **Юридическая публикация.** Заполнить и разместить политику конфиденциальности, контакт поддержки, возрастные категории и обязательные декларации магазина. Текст-заготовка: PRIVACY_RU.md.
7. **Мониторинг реальных ошибок.** Добавить безопасную диагностику с согласия пользователя либо процедуру сбора отчётов, прежде чем объявлять продукт стабильным.

## Безопасная сборка релиза
- В обычной сборке GitHub Actions формируется debug APK.
- Если четыре секрета подписи заданы, дополнительно формируется `LinguaFree-signed-release-apk`.
- После первого выпуска нельзя менять ключ подписи без предусмотренного механизма миграции/управления ключами.
- Увеличивать `versionCode` при каждом обновлении; текущая версия 0.4, code 4.
- Проверять SHA-256 сертификата APK и идентификатор пакета перед распространением.

## Итог
**Внутреннее тестирование: допустимо после успешной сборки и проверки на устройстве. Публичный запуск: пока не рекомендован.** Сборка CI подтверждает компиляцию и статические проверки, но не гарантирует стабильность работы на реальных устройствах.
