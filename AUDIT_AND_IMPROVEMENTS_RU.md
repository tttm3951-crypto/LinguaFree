# LinguaFree 0.3 — аудит и улучшения по методическим принципам

Дата: 17.10.2026. Анализ по исходникам, встроенным материалам и автоматическим сборкам. Это не полноценное тестирование на телефоне.

## Выявленные недостатки
1. Ежедневная цель и уровень из onboarding не загружались из сохранённых настроек при повторном открытии.
2. На главной странице отсутствовал наглядный индикатор выполнения дневной цели.
3. Переход к запланированному повторению требовал открытия статистики.
4. Звук празднования не всегда подчинялся настройке звуковых эффектов.
5. Словарь позволял искать и слушать слова, но не имел отдельного тренажёра карточек.
6. Экспорт резервной копии мог сообщать об успехе при неоткрывшемся потоке записи.
7. Импорт резервной копии не ограничивал размер входного файла.
8. Не было автоматического регрессионного контроля критичных функций при изменениях.
9. Прогресс по отдельным словам привязан к числовым позициям вопросов; после переработки уроков старые интервалы повторения могут ссылаться на изменённые слова.
10. Действующая GitHub Actions debug-подпись не является постоянным релизным ключом, поэтому обновление поверх старого APK может оказаться невозможным.
11. Офлайн-распознавание и офлайн-TTS зависят от установленных системных компонентов Android.
12. Словарь содержит 635 пар, но контекстные примеры есть только у части записей; необходима редакторская проверка лексических значений и уровней.

## Выполнено
- Восстановление сохранённого уровня и ежедневной цели при старте.
- Новый индикатор дневной цели на главной, серия дней, XP, завершённые уроки.
- Быстрый переход к повторению по расписанию.
- Отключение праздничного звука при выключенных эффектах.
- Офлайн-карточки слов: показ перевода, оригинальные примеры, аудиокнопки, «Помню»/«Ещё раз», сохранение результата и срока следующего показа.
- Усиление экспорта и импорта резервной копии.
- Скрипт scripts/validate_app_contract.py для проверки наличия офлайн-данных, прогресса, напоминаний, озвучки и анимаций; интеграция в GitHub Actions.
- Версия приложения 0.3, versionCode 3; идентификатор org.linguafree.app и хранилище linguafree_progress оставлены неизменными.

## Какие идеи использованы из Duolingo
- Понятная ежедневная цель и наглядный прогресс.
- Регулярные короткие повторения.
- Карточки для запоминания и самостоятельная проверка.
- Ненавязчивая игровая обратная связь.
- Все тексты, код, персонаж и звуковые эффекты оригинальные; ресурсы Duolingo не копируются.

## Не завершено
- Проверка сборки текущего коммита GitHub Actions и ручное тестирование на Android.
- Настройка постоянной подписи релизного APK в GitHub Secrets (требует безопасной настройки владельцем).
- Полноценная фонетическая оценка английского без интернета.
- Лингвистическая проверка 300 уроков и словаря носителем/преподавателем.
- Надёжная миграция старой истории повторения на новые устойчивые идентификаторы слов.
- Увеличение словаря до 150 000 проверенных слов и выражений.

## Приёмочные проверки на телефоне
1. Открыть старую установленную версию и сохранить резервную копию прогресса.
2. Проверить подпись нового APK перед обновлением. Не удалять старое приложение без копии.
3. После установки проверить XP, уроки, серию, настройки, напоминания, избранное.
4. Отключить интернет; открыть урок, словарь, историю, карточки, аудио и повторения.
5. Выключить звуковые эффекты и убедиться, что празднование не издаёт сигналов.
6. Выполнить несколько уроков и проверить рост счётчика дневной цели.
7. Проверить восстановление резервной копии на отдельной тестовой установке.
